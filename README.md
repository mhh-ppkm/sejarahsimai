# SejarahSimAI+ v2.1 · Pecutan Terakhir SPM 2026 (Sejarah 1249)

Disediakan oleh **Ir. Ts. Dr. Muhammad Hafiz HASSAN**, Pusat Pengajian Kejuruteraan Mekanik, Universiti Sains Malaysia.

Versi ini mengikut templat keluarga SimAI+ (MathSimAI+, ChemSimAI+, PhysicsSimAI+, BioSimAI+, CivilSimAI+): jalur logo rasmi USM APEX, hero ungu dengan kiraan detik ke kertas Sejarah (Isnin, 30 November 2026), tab melekat di bahagian atas, butang Pasang aplikasi dan footer bernama. Kandungan 20 bab, 140 soalan, Klinik Kertas 2 dan galeri foto kekal seperti v2.0.

## Terbit di GitHub Pages
1. Cipta repositori baharu, contohnya `sejarahsimai-plus`, di akaun `mhh-ppkm`.
2. Muat naik **semua** fail di atas ke akar repositori (bukan dalam folder).
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Buka `https://mhh-ppkm.github.io/sejarahsimai-plus/` selepas 1–2 minit.
5. Untuk video tutorial mp4 seperti simulator lain, letakkan fail mp4 di akar repositori dan kongsi pautannya bersama URL di atas.

## Pasang di telefon (guna luar talian)
- **Android (Chrome):** buka URL, tekan butang **⬇ Pasang aplikasi** dalam hero, atau menu ⋮ → *Install app*.
- **iPhone/iPad (Safari):** tekan Kongsi → *Tambah ke Skrin Utama*.
- Buka aplikasi sekali ketika ada Internet supaya fail, fon dan foto disimpan dalam cache. Selepas itu nota, soalan dan peperiksaan berfungsi tanpa Internet. Foto Wikimedia yang belum pernah dibuka akan memerlukan Internet.
